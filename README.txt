SR Piano v3 - Sampled Instruments

Changes:
- Flute changed from synth to real SoundFont sampled flute
- Harmonium changed from synth to sampled reed organ
- Guitar changed from synth/pluck to sampled nylon guitar
- Organ and strings also use sampled SoundFont instruments
- Piano still uses Salamander sampled piano
- Higher volume output

Internet is required because sampled instruments load from:
- Tone.js CDN
- FluidR3 GM SoundFont CDN
- Salamander piano CDN

Open index.html in Chrome/Edge/Firefox.
Click any instrument button or Start Audio before playing.
